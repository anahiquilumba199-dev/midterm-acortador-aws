# Acortador de enlaces en AWS

Proyecto de mitad de semestre para desarrollar y desplegar
un acortador de enlaces utilizando AWS, FastAPI y JavaScript.

## Tecnologías

- Python
- FastAPI
- Amazon EC2
- Amazon DynamoDB
- Amazon S3
- HTML, CSS y JavaScript
- Git y GitHub

## Funcionalidades

- Crear enlaces cortos.
- Guardar los enlaces en DynamoDB.
- Redirigir al usuario al enlace original.
- Consultar la información de un enlace corto.

## Estructura del proyecto

- `backend/`: API desarrollada con FastAPI.
- `frontend/`: interfaz web del acortador.
